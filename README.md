# Sistema de Banco Virtual (CLI)

Projeto simples de sistema bancário desenvolvido em Python rodando via terminal.

## 🚀 Funcionalidades
- Cadastro e Login de Usuários (com validação de CPF e PIN)
- Consulta de Saldo e Extrato
- Depósito e Saque com tratamento de exceções
- Transferência via PIX entre contas cadastradas

## 🛠️ Tecnologias
- Python 3
